`grove shell-init --install` adds the shell integration to your shell's startup file (`~/.zshrc`, `~/.bashrc` or `~/.bash_profile`, a fish `conf.d` file, or the PowerShell profile) instead of you editing it by hand. It does nothing when a startup file already mentions `grove shell-init`. `grove setup` has a matching **Shell integration** entry that installs it on save.
